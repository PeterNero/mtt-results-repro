# MTT Unified Source Theorem

This repository has one mandate:

> Construct or exclude one selected upper MTT source whose certified readouts
> reproduce the retained q79, quantum, field-theoretic, Standard-Model and
> gravitational structures.

The project begins at **hypothesis tier**. It does not claim a theory of
everything, a selected physical Hull-Strominger background, no-knob Standard
Model values, or UV-complete quantum gravity.

## Repository Boundary

This repository may:

- compare candidate upper sources;
- prove abstract source, uniqueness, transfer and commutativity theorems;
- ingest hash-addressed upstream certificates;
- construct integration verifiers and falsification tests;
- record a single non-looping frontier.

It must not:

- rerun eta9 meridian or period campaigns;
- duplicate the cohesive benchmark theorems already proved upstream;
- fill physical rows from Chern data or observed values;
- rename a repair norm as a Lorentzian action without a shadow theorem;
- promote a finite-symbol identity to a continuum physical result;
- reopen the accepted profile-level SM baseline.
