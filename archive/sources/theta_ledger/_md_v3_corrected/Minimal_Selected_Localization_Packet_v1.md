# Channel Rule

For a trilinear channel:

```text
left_i right_j Higgs
```

assign family labels:

```text
f_i, f_j, f_H in Z3.
```

A channel is family-admissible when:

```text
f_i + f_j + f_H = 0 mod 3.
```

Equivalently, for each pair `(i,j)` there is a unique selected bridge:

```text
b_ij = -(i+j) mod 3.
```

If the bridge is retained by the selected family carrier, every pair has one
finite channel:

```text
Gamma_x[i,j] = {b_ij}.
```

This gives nine finite candidate channels per quark sector, but none are
entry-wise fitted.  Their amplitudes remain symbolic until MTT supplies the
action costs and prefactors.

# Theorem: Minimal Retained Family Cluster

For `eps=0.05`, the operator `L_min` has an isolated three-dimensional
low-energy cluster equal to:

```text
span{|79,f> : f in Z3}.
```

Proof.  At `r=79`, the CP mismatch term vanishes.  The family eigenvalues are
`0, 0.15, 0.15`.  For every `r != 79`, the CP mismatch term is at least `1`.

state tensored with the three family labels.  The separation from the excluded
sector is at least `0.85`.
