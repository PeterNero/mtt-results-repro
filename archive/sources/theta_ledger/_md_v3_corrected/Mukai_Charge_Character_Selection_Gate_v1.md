# Purpose

The Mukai block now carries the odd factor:

```text
K_Mukai =
[[2,1],
 [1,4]].
```

This note states exactly what this proves and what remains open.

# Formal character result

The Smith normal form is:

```text
SNF(K_Mukai)=[7].
```

Therefore:

```text
coker K_Mukai ~= Z_7.
```

The unitary characters are:

```text
Hom(coker K_Mukai,U(1)).
```

Equivalently, they are solutions of:

```text
K_Mukai^T theta = 0 mod 1.
```

Since `K_Mukai` is symmetric, this is the same matrix.

An explicit generator is:

```text
theta = (1/7,5/7).
```

Indeed:

```text
2*(1/7) + 1*(5/7) = 1 = 0 mod 1,
1*(1/7) + 4*(5/7) = 21/7 = 3 = 0 mod 1.
```

Thus:

```text
theta has order 7.
```

# What is proved

The following is proved:

```text
the Mukai charge block has cyclic quotient Z_7,
the character dual is cyclic of order seven,
the generator is explicit,
the formal odd CP character arithmetic is complete.
```

# What is not proved

The remaining theorem is not arithmetic.  It is selection:

```text
MTT fixed sector
  -> Fu-Yau/K3 integral Mukai charge lattice
  -> quotient by K_Mukai
  -> Hom(coker K_Mukai,U(1)).
```

We must prove that the physical CP labels are exactly these unitary characters.

# Candidate selection map

A clean selection theorem would say:

```text
In the selected Fu-Yau/K3 fixed sector, the family-trivial odd CP data factor
through the integral Mukai charge quotient:

Q_odd := Lambda_Mukai / K_Mukai Lambda_Mukai.

The odd CP phase group is Hom(Q_odd,U(1)).
```

Then:

```text
Q_odd ~= Z_7,
Gamma_7 ~= Hom(Q_odd,U(1)) ~= Z_7.
```

# Relation to HYM/bundle realization

This is a charge-character statement, not a claim that the two Mukai vectors
are two summands of one HYM bundle.

That caveat matters because:

```text
a=(5,H,0),
b=(7,3H,1)
```

have different slopes.  The same-slope two-summand route is obstructed.

So the viable interpretation is:

```text
Mukai charge-lattice quotient first,
stable/HYM or Fu-Yau anomaly realization as a separate gate.
```
