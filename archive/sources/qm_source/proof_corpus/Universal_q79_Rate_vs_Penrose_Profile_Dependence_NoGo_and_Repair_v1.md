# Universal q79 Rate versus Penrose Profile Dependence: No-Go and Repair

## No-Go Theorem

Let `gamma0>0` be the profile-independent rate supplied by the canonical q79
`P/Q` clock. The regulated Penrose energy is a quadratic form in the branch
mass-density difference:

```text
E_G[c delta_mu]=c^2 E_G[delta_mu].
```

Consequently `gamma0=E_G[delta_mu]/hbar` cannot hold for every physical branch
pair. If it holds for one nonzero `delta_mu`, scaling that difference by two
multiplies the right side by four while leaving `gamma0` fixed. Identical branch
profiles also have zero Penrose rate, contradicting a universal positive rate.

Thus the q79 reference rate cannot be identified with a universal
profile-independent objective-collapse rate.


The same q79-selected dephasing shape is reused, while its physical rate varies
with the prepared branch profiles. The dimensionless `r_C` is context/state
data, not a new universal fitted constant.
