# Purpose

The selected overlap-kernel certificate defines the object needed for full
no-proxy flavor closure.  This note records the part that can already be
proved from the closed q79 branch alone.

# Closed Character Input

The terminal certificate gives:

```text

q=79.
```

Define:

```text
tau := exp(2 pi i q/448)
     = exp(2 pi i 79/448).
```

Because:

```text
gcd(79,448)=1,
```

`tau` has exact order `448`.

# Theorem: Phase Rigidity

In any no-proxy selected overlap-kernel packet extending the q79 branch, every
CP-sensitive Yukawa phase lies in the finite character algebra:

```text
C[Z448] = span_C{tau^w : w in Z448}.
```

Equivalently, the only primitive CP phase generator available to the selected
kernel is:

```text
tau = exp(2 pi i 79/448).
```

Proof.  By the selected overlap-kernel certificate, every admissible channel
has a finite CP weight:

```text
w_gamma in Gamma_CP.
```

The terminal q79 theorem identifies:

```text
Gamma_CP ~= Z448
```

and selects the physical character:

```text
chi_q(w)=exp(2 pi i q w/448)=tau^w.
```

Therefore every CP-sensitive summand in every raw Yukawa entry is a real
selected amplitude multiplied by `tau^w`.  Finite sums of such terms lie in
the character algebra generated by `tau`.  Since `gcd(79,448)=1`, the
generator has exact order `448`.  Hence the CP phase content is rigidly
confined to the selected `Z448` character algebra.

# Corollary: No New Independent CP Knobs

Once the q79 branch is fixed, a later Yukawa packet cannot introduce arbitrary
continuous CP phases without breaking same-source closure.

Any additional phase must be one of:

```text
tau^w,  w in Z448,
```

or must be proved to come from a different selected sector that is then
included in the source map and audited as part of `Sigma_MTT`.

# Theorem: Magnitude Under-Determination from q79 Alone

The q79 finite character alone does not determine CKM angle magnitudes or
Yukawa singular values.

Proof.  The same finite phase data permit distinct positive amplitude systems:

```text
B_gamma > 0.
```

For a one-channel entry:

```text
Y[i,j] = B tau^w.
```

Changing `B` changes the singular values of the matrix but leaves the selected
finite CP character unchanged.  For multi-channel entries, changing the action
costs and prefactors changes magnitudes and interference patterns while still
keeping every phase in the same `Z448` character algebra.

Therefore q79 fixes a finite CP phase source, not the full flavor magnitude
data.  The missing quantities are exactly the action costs, prefactors,
channel sets, and kinetic metrics named in the selected overlap-kernel
certificate.
