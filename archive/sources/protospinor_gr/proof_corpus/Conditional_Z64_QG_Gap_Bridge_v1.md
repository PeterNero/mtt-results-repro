# Conditional Z64/QG Gap Bridge v1

## Result

The exact Z64/QG bridge is closed conditionally.

If:

- the exact Z64 central-circle tower is retained by `Pi_coh`,
- the selected operator commutes with `Pi_coh`,
- the excluded block `Q` is the QG noncoherent complement,
- the normalized exact-branch value `lambda_* = 15` is the relevant internal
  gap,

then:

```text
C_fl = 0
E_Schur = 0
lambda_Q >= 15
sqrt(lambda_Q) >= 3.872983346207417
tau0 <= 1/15 if saturated
```

## Meaning

This is strong for the exact finite flavor/CP branch: the Schur correction
vanishes and the gap denominator is harmless.

It is not yet full GR modal-gap closure. The GR proof still needs to show that
its `A_int` noncoherent complement is the same exact Z64 central-circle tower
block, or else compute the corrected selected branch.
