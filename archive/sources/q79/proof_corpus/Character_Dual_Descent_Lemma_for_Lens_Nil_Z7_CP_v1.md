# Purpose

The fixed-sector theorem reduced the Lens-Nil problem to this question:

```text
Why should the Bianchi/gerbe component matrix act on CP phase labels?
```

The correct answer is not that metric coefficients literally become phases.
The correct answer is dual:

```text
integral Bianchi/gerbe relations define a quotient lattice;
flat Wilson/holonomy CP phases are unitary characters of that quotient.
```

# Formal lemma

Let:

```text
Lambda_Z ~= Z^2
```

be the fixed Lens-Nil arithmetic component lattice in the family-trivial
sector.  Let:

```text
K: Lambda_Z -> Lambda_Z
```

be the exact integral Bianchi/gerbe relation map.  The component quotient is:

```text
Q_K := Lambda_Z / K Lambda_Z.
```

The residual flat CP character group is:

```text
Gamma_K := Hom(Q_K, U(1)).
```

Equivalently:

```text
Gamma_K = {chi in Hom(Lambda_Z,U(1)) : chi(K lambda)=1 for all lambda}.
```

Choose coordinates:

```text
theta = (w,n) in (R/Z)^2.
```

Then the character equations are:

```text
K^T theta = 0 in (R/Z)^2.
```

This transpose is important.  The relation matrix acts on lattice generators;
the dual matrix acts on characters.  In the Lens-Nil case:

```text
K_LN =
[2 1
 1 4]
```

is symmetric, so the character equations look identical:

```text
2w + n  = 0,
w  + 4n = 0
```

in `R/Z`.

# Sevenfold solution

Solve:

```text
2w+n=0,
w+4n=0
```

in `R/Z`.

From the first equation:

```text
n = -2w.
```

Substitute into the second:

```text
w + 4(-2w) = -7w = 0.
```

Thus:

```text
w in (1/7)Z/Z,
n = -2w.
```

The seven characters are:

```text
j -> (w,n) = (j/7, -2j/7) mod 1,
j = 0,...,6.
```

So:

```text
Gamma_K ~= Z_7.
```

# What this achieves

This proves a formal bridge:

```text
if the fixed Lens-Nil component quotient is coker(K_LN),
then the residual holonomy/CP phases form Z_7.
```

It also explains why the phase equations can be written using the same matrix
as the component relations in this special case:

```text

```
